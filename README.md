# Loan Repayment Prediction System

## Project Overview
This project predicts whether a customer will repay a loan or default.

## Features
- Data loading
- Data preprocessing
- Logistic Regression model training
- Model evaluation
- Automated testing
- CI/CD pipeline with GitHub Actions

## Tech Stack
- Python
- Pandas
- Scikit-learn
- Pytest
- Pylint
- Black
- GitHub Actions

## Run Project
```bash
python main.py
